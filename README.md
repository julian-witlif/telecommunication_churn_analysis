# Telecommunications Customer Churn Analysis

This project explores customer churn in a telecommunications dataset. SQL queries compare churn rates across customer groups, while a logistic regression model in Python estimates each customer's probability of churning and examines the factors associated with churn. An Excel workbook provides additional visualizations.
